# 宠物消费记录

消费记录是用户主动记录的现实养宠财务支出，所有接口都从已认证 JWT 读取用户身份。`pet_id` 可为空，表示公共养宠支出；填写宠物时，服务端会校验宠物属于当前用户。

金额使用 `DECIMAL(10,2)` 和 Java `BigDecimal` 保存，范围为 `0.01` 至 `999999.99`。列表、摘要和统计都只查询当前用户未删除的数据；删除采用软删除。

## 医疗记录的费用字段

`medical_record.cost` 是就医档案中的医疗信息；`expense_record` 是用户单独录入的财务支出。两者不会自动同步，也不会因同一笔就医而互相创建，避免重复记账和双重事实来源。

疫苗和驱虫记录不增加金额字段。用户需要统计相关开销时，可在消费记录中单独创建 `VACCINE` 或 `DEWORMING` 分类的支出。
